# OpenSpec Changes

This directory contains implementation proposals derived from [spec.md](C:\Temp\GitHub\M365Cli\spec.md).

The initial proposals intentionally split the product into four change sets:

1. `add-cli-foundation`
2. `add-auth-profiles`
3. `add-mail-calendar`
4. `add-files-graph`

Each change contains:

- `proposal.md`: problem statement, scope, and impact
- `tasks.md`: implementation checklist
- `specs/*/spec.md`: normative requirements and scenarios

These proposals are a planning baseline for implementing `mog` as described in the source product specification.
